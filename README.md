# test.catalogodatos.gub.uy -- removed from the catalog

This repository used to profile test.catalogodatos.gub.uy as a data provider. It is the test instance of
Uruguay's national CKAN open-data catalogue, not a publisher: the production portal, catalogodatos.gub.uy,
is catalogued separately (catalogodatos-gub-uy) and stays.

It was removed on 2026-09-24 as a catalog-hygiene decision by API Evangelist (roadmap#684). Nobody asked.

The slug and the test host are on the delisting registry (api-search/network/_data/delisted.yml), so
harvests will not re-add this record. The production portal is not on the registry. Questions: info@apis.io.
